# 知识产权与商标规避说明

> 本文是开发约定，不是法律意见。正式上线前请 PICO／字节法务审核。

## 原则：虚构载具，真实科学

| 元素 | 做法 |
|---|---|
| 公司、探测器 | 全部虚构：「星驿快递」「小驿号」。外形由 AI 根据原创描述生成，没有参照任何真实型号 |
| 真实任务名、型号名（神舟、天宫、嫦娥 X 号等） | **游戏内不使用**，包括关卡名、角色名和标题 |
| 官方标志、徽标、照片、视频、官方 3D 模型 | **一律不用**。生成图片的提示词里都写了 no logos / no flags / no emblems |
| 真实历史和科学事实 | 只在「航天图鉴」窗口里用客观文字陈述，不点名具体任务，例如「2019 年 1 月，中国的探测器在月球背面实现软着陆」 |
| 天体名称（地球、月球、火星等） | 天文学通用名称，可以使用 |
| 玩法 | 引力弹弓是物理概念。关卡、角色和界面都是原创，没有参照《愤怒的小鸟太空版》 |
| 失败表现 | 失败的是虚构的「小驿号」，不涉及真实国家任务 |

## 素材来源

所有贴图和模型都由火山方舟生成（Seedream 5.0 出图，Seed3D 2.0 出模型），提示词见 `assets_lab/gravity/*.json` 和 `*.prompt.txt`。陨石模型、月球和火星用的球体和法线贴图、星空环境光贴图由本仓库的脚本从上述素材或程序噪声生成（`tools/make_rocks.py`、`tools/make_sphere.py`、`tools/normal_from_height.py`、`tools/polar_blend.py`、`tools/wrap_seam.py`、`tools/ibl_source.py`；应用图标由 `tools/make_icon.py` 用游戏里已有的探测器模型、地球贴图和天空渲染而成；环境光贴图再用 Apache-2.0 授权的 Filament `cmgen` 处理），不引入新的第三方素材。地球贴图是把 Seedream 生成的椭圆投影地图，用程序拉伸成 2:1 展开图得到的。

## 图鉴事实核对（2026-10-22 新增的 5 张卡）

新卡同样只陈述客观事实，不点名具体任务。数字的出处和换算如下，上线前可以再请专业人士过一遍。

| 卡片 | 说法 | 依据 |
|---|---|---|
| 地球 | 直径约 12742 公里，约 71% 是海洋，自转轴倾斜约 23.4° | NASA Earth Fact Sheet |
| 空间站 | 高度约 400 公里，每秒约 7.7 公里，约 90 分钟一圈，一天约 16 次日出 | NASA、ESA 对国际空间站的介绍（周期约 92 分钟，24 小时 ÷ 92 分钟 ≈ 15.7） |
| 空间站 | 那里的重力接近地面的九成 | (6371 / 6771)² ≈ 0.89 |
| 空间站 | 想追上前面的空间站，要先降到更低的轨道 | 开普勒第三定律：轨道越低周期越短，这是交会对接的基本原理 |
| 探测器家族 | 1977 年发射的一个飞掠探测器在 2012 年飞出日球层顶，是离地球最远的人造物体 | NASA 旅行者 1 号任务页（2012 年 8 月穿越日球层顶） |
| 探测器家族 | 2020 年，中国的探测器从月球带回 1731 克样品 | 新华社、中国科学院公开报道 |
| 轨道修正 | 在离天体最近、速度最快时点火最省燃料（奥伯特效应） | 轨道力学教材；游戏里点火是把速度乘以 1.35，速度越快，加的速度越多，所以同样符合这个规律 |
| 真实比例 | 地球缩到直径 40 厘米时：月球 11 厘米、在 12 米外；火星最近约 1.8 公里；木星 4.4 米、约 18 公里；太阳 44 米、约 4.7 公里 | 比例 0.4 m / 12742 km，代入月球距离 38.44 万公里、直径 3474 公里，火星最近距离约 5600 万公里，木星最近距离约 5.9 亿公里、直径约 14 万公里，日地距离 1.496 亿公里、太阳直径 139 万公里 |
| 真实比例 | 光从月球到地球约 1.3 秒，从太阳到地球 8 分多钟 | 384400 km ÷ 299792 km/s ≈ 1.28 s；1.496 亿 km ÷ 光速 ≈ 499 s |

另外顺手修正了一处旧卡的说法：「深空通信」里从木星发回信号的时间，从「30 多分钟」改成「30 到 50 多分钟」（地木距离在约 5.9 亿到 9.7 亿公里之间变化）。
